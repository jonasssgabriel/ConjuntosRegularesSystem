📖 Definição Central (Jackson, slide 4)

Conjuntos e expressões regulares são notações alternativas usadas para representar a classe das linguagens regulares — a mais restrita da Hierarquia de Chomsky. Enquanto um autômato finito é usado como reconhecedor de cadeias, uma expressão regular é um gerador de cadeias de uma linguagem.

Hierarquia de Conceitos

a, b, 0, 1
Símbolo (σ)
→
Σ = {a,b}
Alfabeto (Σ)
→
aba, ba, ε
Cadeia (w)
→
{aba, ba, a, ...}
Linguagem (L)

Uma sentença é qualquer cadeia que pertença à linguagem L.

Seção 02

Conceitos Básicos

Fundamentos que você precisa conhecer antes de mergulhar nas expressões regulares.

ε

Cadeia Vazia (ε)

A cadeia vazia é a cadeia com zero símbolos. Ela pertence a Σ* para qualquer alfabeto Σ. Representa "nada" — e é a base do fechamento de Kleene.

Σ*

Fechamento de Kleene (Σ*)

Conjunto de todas as cadeias possíveis sobre Σ, incluindo a cadeia vazia ε. Se Σ = {a,b}, então Σ* = {ε, a, b, aa, ab, ba, bb, aaa, ...} — infinito!

Σ⁺

Fechamento Transitivo (Σ⁺)

Todas as cadeias sobre Σ com comprimento ≥ 1. Equivale a Σ* sem a cadeia vazia: Σ⁺ = Σ* − {ε}. É a "versão obrigatória" do Kleene.

D

D*, D⁺ e DD* (diferença)

D* inclui ε. D⁺ = DD* exige ao menos 1 dígito (sem ε). DD* é a forma explícita de D⁺ — um dígito seguido de zero ou mais. Todos representam os números naturais, mas DD* deixa claro.

L

Linguagem Regular

Um conjunto de cadeias que obedece a um padrão definível por expressão regular ou autômato finito. É a classe mais restrita da Hierarquia de Chomsky (Tipo 3).

w

Sentença

Uma sentença é qualquer cadeia w que pertença à linguagem L, ou seja, w ∈ L. Se a linguagem é "números naturais", então "42" é uma sentença dessa linguagem.

Seção 03

Conjuntos Regulares

Conjuntos regulares sobre Σ são linguagens definidas recursivamente. Qualquer linguagem regular pode ser construída a partir dos casos base usando as operações abaixo.

📌 Casos Base (Jackson, slide 6)

∅

Conjunto Vazio

∅ é um conjunto regular sobre Σ. Representa a linguagem sem nenhuma cadeia. A ER ∅ não reconhece nada.

{ε}

Conjunto com ε

{ε} é um conjunto regular sobre Σ. Representa a linguagem que contém apenas a cadeia vazia.

{σ}

Símbolo unitário

{σ}, ∀σ ∈ Σ, é um conjunto regular. Cada símbolo do alfabeto forma por si só um conjunto regular (com uma única cadeia).

Operações sobre Conjuntos Regulares

Se X e Y são conjuntos regulares sobre Σ, os seguintes conjuntos também são regulares:

X ∪ Y
União
Contém as cadeias que estão em X ou em Y. Na ER: x | y ou x + y.
X · Y
Concatenação
Todas as cadeias formadas juntando uma cadeia de X com uma de Y. Na ER: xy.
X*
Fechamento de Kleene
Zero ou mais concatenações de X consigo mesmo. Inclui sempre ε. Na ER: x*.
(X)
Agrupamento
Parênteses alteram a precedência dos operadores, assim como na matemática tradicional.

Exemplos do material (slides 7 e 8)

Números Naturais — slide 7
N = DD*

Com D = {0,1,...,9}, a linguagem N dos números naturais é o conjunto regular DD*. Equivalentemente: D⁺. Aceita: 27, 1, 999. Rejeita: ε, abc.

Números Reais — slide 8
R = DD*.D* ∪ D*.DD*

Números reais decimais sem sinal sobre D ∪ {.}. Exemplos: 27, 915.4, .315, 47. Note que N ⊂ R mas R ≠ N.

Seção 04

Expressões Regulares

Notação alternativa desenvolvida por Kleene (décadas de 1950). Uma expressão regular (ER) é um gerador de cadeias de uma linguagem — L(r) ou GERA(r).

📐 Definição Recursiva das ERs (Jackson, slide 10)

∅

∅ — Conjunto vazio

ER que denota o conjunto vazio. Nenhuma cadeia é gerada.

ε

ε — Cadeia vazia

ER que denota {ε}. Gera apenas a cadeia vazia.

σ

σ ∈ Σ — Símbolo

Cada símbolo do alfabeto é uma ER e denota {σ}.

x | y
União (x+y ou x|y)
Denota X ∪ Y. Operador de menor precedência.
xy
Concatenação
Denota XY. Precedência intermediária.
x*
Kleene (zero ou mais)
Denota X*. Maior precedência de todas.
x⁺
Kleene Transitivo (≥1)
xx* = x⁺. Um ou mais. Nunca aceita ε.

Tabela de Precedência dos Operadores (slide 11)

Precedência Operador Símbolo Exemplo Leitura
Mais Alta — 1° Fechamento de Kleene x* ab* a concatenado com (b*)
Intermediária — 2° Concatenação xy abc a concatenado com b concatenado com c
Mais Baixa — 3° União x | y   x + y a | bc* a OU (b concat (c*))
(modificador) Parênteses (x) (a|b)* zero ou mais de (a ou b)

Exemplo de precedência (Jackson, slide 12)

(ab | c*)
= ((ab) | (c*)) → {ab, ε, c, cc, ccc, ...}
a(b|c)*
→ {a, ab, ac, abc, abb, ...} começa com a
(ab|c)*
→ {ε, ab, c, abc, cab, abab, cc, ...}

Seção 05

Passo a Passo: Como usar uma ER

Guia prático para construir e testar uma expressão regular do zero.

1

Defina o Alfabeto (Σ)

Determine quais símbolos podem aparecer na linguagem. Ex.: Σ = {0,1} para binários; Σ = {a,b,c} para palavras; D = {0..9} para dígitos.

2

Descreva o Padrão desejado

Em linguagem natural: "cadeias que começam com a" ou "sequências de dígitos com pelo menos um". Esclareça se ε é aceito.

3

Monte a Expressão Regular

Use os operadores: * (zero ou mais), + (um ou mais), | (união), concatenação implícita e parênteses para agrupar.

4

Teste Cadeias de Exemplo

Escolha cadeias que deveriam ser aceitas e outras que não deveriam. Use o simulador abaixo para verificar.

5

Verifique Pertencimento (w ∈ L?)

A cadeia está na linguagem? O resultado é "pertence" (✓) ou "não pertence" (✗). Observe o conjunto regular correspondente.

6

Analise o Reverso (wᴿ)

Inverta a cadeia e observe se o reverso também pertence. O reverso de uma linguagem regular também é regular!

Seção 06

Inversão de Cadeias (Reverso)

A inversão de uma cadeia w coloca seus símbolos em ordem contrária. Se w = abc, então wᴿ = cba. O reverso de uma linguagem é o conjunto formado pelo reverso de cada cadeia pertencente a ela — e continua sendo regular!
